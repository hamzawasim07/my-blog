Welcome! This is the first post on my new blog. It is a simple, fast site built with Next.js and deployed on Vercel.

## What you will find here

I plan to write about things I am learning and working on. Posts are short, practical, and written in plain language.

## How publishing works

Every post is a Markdown file in the `posts` folder. To publish a new one:

1. Create a new file such as `posts/my-new-post.md`.
2. Add the title, date, and excerpt at the top.
3. Write your content below it.
4. Commit and push to GitHub. Vercel deploys it automatically.

That is all it takes.
