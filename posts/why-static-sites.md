title: "Why Static Sites Still Make Sense"
date: "2026-10-28"
excerpt: "Fast, secure, and cheap to host: the case for a simple static blog."
---

A blog does not need a database or a complicated backend. For most writers, a static site is the better choice.

## Speed

Pages are generated once at build time and served from a CDN. There is nothing to compute when a visitor arrives, so pages load almost instantly.

## Security and cost

With no server running application code, there is very little to attack, and hosting is often free at small scale.

## Simple workflow

Your posts live in Git alongside the code. You get version history, easy backups, and the ability to write from any editor.

If you only need to publish words, a static site is hard to beat.
